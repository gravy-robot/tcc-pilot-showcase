# `examples.json` schema

Generated by `tools/build_content_example.py` from `reference/audit.md`. One record per row in the audit's two tables (8 health, 10 athlete). Field names follow `reference/requirements/content-example-requirements.md`, section 3. Fields the audit doesn't support are `null`, and the pages say so.

The file also holds `pairs`: the three contrast pairs (`id`, `title`, `strong`, `weak`, `lesson`).

**Source key:** **A** = parsed from the audit tables · **N** = paraphrased from the audit's notes · **D** = draft curation for prototyping, derived from the audit text (listed in `prototype_curation_fields`) · **G** = set by the generator · **Y** = seen on the YouTube page · **—** = always `null` in this prototype.
